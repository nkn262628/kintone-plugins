# ERP 自動編號外掛 使用說明

## 📁 檔案結構

```
erp-autonumber-plugin/
├── manifest.json          外掛宣告檔
├── html/
│   └── config.html        設定頁面 HTML
├── js/
│   ├── config.js          設定頁邏輯
│   └── desktop.js         App 主程式（桌機 + 手機共用）
├── css/
│   ├── config.css         設定頁樣式
│   └── desktop.css        App 端樣式（保留擴充用）
└── image/
    └── icon.png           外掛圖示（請自行準備 48x48 png）
```

## 📦 打包方式

```bash
# 進入外掛資料夾後，用 kintone plugin packager 打包
npx @kintone/plugin-packer ./
```
打包後會產生 plugin.zip，即可在 Kintone 系統管理 > 外掛 上傳。

---

## ⚙️ 設定說明（每個 App 獨立設定一次）

1. 進入 App 設定 > 外掛 > ERP 自動編號外掛 > 設定
2. **快速套用預設**：點選對應模組按鈕，自動帶入建議前綴
3. 填入「編號欄位代碼」（Kintone 欄位的欄位代碼，非欄位名稱）
4. 確認「前綴代碼」、「流水號位數」、「重置規則」
5. 若需依條件分段，填入「依條件分段編號」欄位代碼，並新增對應關係
6. 按「儲存設定」

## 📋 功能說明

### ✅ 支援功能
- **桌機 + 手機**：同一支 `desktop.js` 同時掛載到 desktop / mobile 事件
- **複製記錄不帶號**：複製後儲存時走「新增」流程，自動產生全新編號
- **欄位唯讀**：`create.show` / `edit.show` 時自動 `disabled = true`，防止手動輸入
- **Toast 提示**：Loading / 成功 / 失敗三種狀態，不使用 `alert()`
- **條件分段前綴**：如廠商資料依「單位類別」欄位值決定 HQ- / WH- 前綴

### 🔄 流水號重置模式
| 模式 | 說明 | 適用場景 |
|------|------|---------|
| 每日重置 | 每天從 001 開始 | 採購單、銷貨單（單量大） |
| 每月重置 | 每月從 001 開始 | 款項類 |
| 永不重置 | 序號一直累加，不歸零 | 主檔資料（客戶、廠商、商品） |

### ⚠️ 注意事項
- **欄位型態**：建議使用「文字」欄位
- **查詢邏輯**：使用 `like` 搜尋同前綴+日期的最大號，高並發（同一秒多人新增）有極低機率重號，一般 ERP 使用量不需擔心
- **icon.png**：打包前需準備一個 48x48 px 的 PNG 圖示放在 `image/` 資料夾

## 🔧 廠商資料條件分段設定範例

廠商資料 App 有「單位類別」欄位，值為「公司/分公司/倉庫」：

| 單位類別 | 前綴 |
|----------|------|
| 公司 | HQ |
| 分公司 | HQ |
| 總公司 | HQ |
| 倉庫 | WH |

設定方式：
1. 「前綴代碼」欄位填入 `VD`（作為 fallback）
2. 「依條件分段編號」填入 `單位類別`
3. 新增條件：`公司 → HQ`、`分公司 → HQ`、`總公司 → HQ`、`倉庫 → WH`
