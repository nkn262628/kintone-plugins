ERP 自動編號外掛

設定此應用程式的自動編號規則

▾
使用說明
  • 編號欄位將自動設為唯讀，防止手動編輯
  • 複製記錄後，儲存時會自動產生全新編號，不會沿用原編號
  • 電腦版與手機版皆支援
  • 若同一天有大量新增，請確認流水號位數足夠

⚡ 快速套用預設

選擇對應的 ERP 模組，自動填入建議設定

📝 基本設定

請填入 Kintone 欄位的「欄位代碼」（非欄位名稱）

PO-20250629-001

建議使用 2–4 個大寫英文字母，系統會自動加上日期與流水號

🔧 進階設定

填入欄位代碼後，系統會依該欄位值決定前綴（需搭配下方條件對應表）

條件前綴對應表

當「依條件分段」欄位為指定值時，覆蓋使用對應前綴

👁 編號格式預覽

PO - 20250629 - 001
前綴 日期（YYYYMMDD） 流水號
